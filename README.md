# 🏨 Hostel Management System

A desktop-based **Hostel Management System** developed using **Python** and **Tkinter**. The application helps hostel administrators manage students, rooms, visitors, leave applications, and student in/out records through a simple graphical user interface.

---

## 📌 Features

- 👨‍🎓 Add New Student
- 🏠 Add New Hostel Rooms
- 🛏️ Room Allocation
- ⏰ Student In/Out Time Management
- 👥 Visitor Management
- 📄 Leave Application Management
- 📋 View Student Information
- 🔐 Login Authentication
- 💾 Text File Database Storage

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (GUI)
- File Handling
- OS Module
- Datetime Module
